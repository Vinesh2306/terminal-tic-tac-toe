# Terminal Tic-Tac-Toe

A terminal-based Tic-Tac-Toe game built with Python, where a human player plays against an intelligent computer opponent.

## Features

* Human vs Computer
* Human plays as X
* Computer plays as O
* Minimax AI
* Winner detection
* Draw detection
* Input validation
* Play again option
* Runs directly in the terminal

## How to Play

The board positions are:

```text
1 | 2 | 3
---------
4 | 5 | 6
---------
7 | 8 | 9
```

Enter a number from 1 to 9 to place your X.

The first player to get three symbols in a row wins.

## Computer AI

The computer uses the Minimax algorithm to evaluate possible moves and select its move.

This allows the computer to play strategically instead of simply choosing a random position.

## Technologies Used

* Python
* Terminal / Command Line
* Minimax Algorithm

## How to Run

Make sure Python is installed on your computer.

Run the following command from the project folder:

```bash
python tictactoe.py
```
